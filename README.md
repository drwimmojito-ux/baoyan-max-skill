# 保研工作台

<p align="center"><img src="assets/logo.png" alt="保研工作台标志" width="160" /></p>

保研工作台是面向个人使用的保研申请管理网页。它集中管理院校项目、申请进度、材料清单、重要日期和面试笔记，并支持导出、导入 JSON 备份。填写的数据保存在当前浏览器中。

## 运行方式

1. 下载或克隆本仓库。
2. 直接打开 `index.html`，或在仓库目录启动任意静态文件服务器后访问首页。
3. 点击“开始我的规划”清除演示数据，建立自己的项目。

项目由原生 HTML、CSS、JavaScript 构成，无构建步骤或第三方运行依赖。当前版本可作为静态站点部署到 GitHub Pages；部署只发布网页代码，使用者填写的项目数据不会随仓库上传。

## 功能

- 添加、编辑、删除申请项目，并在“待调研 → 准备中 → 已提交 → 待面试”之间调整阶段。
- 记录申请类型、日期及备注；搜索项目，查看近期日期和未来七天截止数量。
- 管理材料清单，勾选完成状态，添加或删除自定义材料。
- 在设置中导出和导入 JSON 备份。
- 在桌面和窄屏设备上使用响应式界面。

## 数据与隐私边界

- 个人数据写入当前浏览器的 `localStorage`，键名为 `baoyan-workbench-v1`。应用代码没有账户、后端、分析脚本或远程同步请求。
- 同一站点在不同浏览器或浏览器配置文件中的数据各自独立；同一浏览器配置文件中的使用者会共用这份数据。因此共用电脑时应使用独立的系统账户或浏览器配置文件。
- 清除站点数据、使用隐私浏览模式、变更站点域名或设备，都可能使原数据无法访问。迁移前应先导出 JSON 备份，再在目标设备导入。
- `localStorage` 不提供数据加密。不要在备注中保存身份证号、登录凭据或其他敏感信息；导出的 JSON 文件同样需要妥善保管。
- 静态托管服务仍可能记录访问网页时的常规网络日志（例如 IP 地址）；这里的“本地保存”特指用户在应用中填写的项目与材料数据。
- 演示院校及日期只是界面示例。真实招生要求、截止日期和资格条件应以各院校官方通知为准。

## 后续可选方向

1. **离线优先**：加入 Service Worker，使已打开过的应用在断网时仍可启动。
2. **更强的本地安全**：提供用户自设口令的加密备份；需先明确密钥丢失后的恢复策略。
3. **申请资料模板**：提供可复制的面试问题、邮件草稿及材料检查项，但应与个人记录分开存储。
4. **可验证的信息来源**：若未来加入院校信息检索，应标明来源链接和抓取时间，不把模型生成内容当作官方通知。
