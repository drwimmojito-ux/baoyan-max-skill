# 保研工作台

<p align="center"><img src="assets/logo.png" alt="保研工作台标志" width="160" /></p>

保研工作台是面向个人使用的保研申请管理应用。每位使用者在自己的电脑系统账户中管理院校项目、申请阶段、材料文件、日程提醒和保研咨询资料。应用没有账户、自建后端或自动同步。只有使用者主动点击“发送给配置的 AI”时，本次问题、手册链接索引及勾选附带的个人资料才会发往使用者配置的模型服务商。

当前是可直接运行的 **Electron 桌面开发版**。界面仍由原生 HTML、CSS、JavaScript 编写，可以直接编辑和预览。尚未制作 Windows 安装包。

## 运行桌面版

环境：Windows 电脑，Node.js 与 npm。首次安装依赖时需要联网；本地管理功能以后不依赖网络。AI 咨询与打开在线手册链接需要联网。

```powershell
npm install
npm start
```

窗口右上角的关闭按钮会将应用留在系统托盘，以便继续检查到期提醒。要彻底退出，请在托盘图标上打开菜单并选择“退出”。托盘菜单也可以重新打开工作台。

首次启动显示演示数据。点击“开始我的规划”建立空白清单。演示项目和日期仅用于展示，不代表真实招生信息。

## 本机数据与备份

桌面版的清单写入 Electron 用户数据目录中的 `state.json`；材料文件复制到该目录的 `materials/`，附件索引记录在 `materials.json`；咨询资料与模型配置写入 `consult.json`。API Key 由当前系统账户的安全存储加密后再写入。Windows 上的数据目录通常位于 `%APPDATA%\baoyan-workbench`；请以应用“设置 → 本机数据目录”显示的路径为准。不同 Windows 系统账户有各自的数据目录。

完整备份：从系统托盘退出应用，再复制整个数据目录。恢复时也应先退出应用，再将整个目录放回原位置。加密后的 API Key 与原系统账户绑定，跨系统账户恢复时需重新填写 Key。设置页导出的 JSON **只包含项目、材料清单和提醒，不包含上传文件、咨询资料或 API Key**。

浏览器预览与桌面版使用独立的数据空间。此前保存在浏览器中的项目可通过 JSON 导出和导入桌面版；浏览器附件需要逐个下载后在桌面版重新添加。请先核对导入内容，因为导入会替换当前清单并删除当前材料文件。

## 系统提醒

在“日程提醒”中创建事项并选择具体日期与时间。到点后，运行中的桌面版调用电脑的系统通知；窗口留在托盘中也会继续检查。应用完全退出期间错过的提醒会在下次启动时补发。系统休眠后恢复时也会检查；常规检查间隔约 30 秒。

请在日程页点击“发送测试通知”，并确认系统实际显示了通知。Windows 的通知开关、专注模式或系统策略可能阻止通知显示。设置页可选择开机启动，以便登录电脑后让应用在后台检查提醒。**项目卡片上的截止日期只是记录日期，不会自动生成系统提醒**；可在日程页为该项目单独设置提醒。完全关机或应用退出时，无法在指定时刻弹出通知。

## 功能

- 新增、编辑、删除院校项目；在申请看板中把项目移到“待调研”“准备中”“已提交”“待面试”等阶段。
- 搜索项目，记录申请类型、截止日期和备注。
- 新增、改名、删除材料条目；添加、更换、另存和删除材料文件。
- 新增、编辑、完成和删除提醒；桌面版使用系统通知。
- 在“AI 咨询”中搜索 35 条飞跃手册及保研资料入口，查看每条入口的申请类型、适用范围和核查状态。
- 编辑、保存和下载 Markdown 个人资料；生成可交给本仓库 Codex Skill 的提问，或主动请求自行配置的 OpenAI 兼容模型接口。
- 导出和导入清单 JSON；桌面版显示本机数据目录。

## 保研咨询 Skill 与手册索引

仓库包含 [保研咨询 Skill](skills/baoyan-advisor/SKILL.md)、[飞跃手册来源说明](skills/baoyan-advisor/references/feiyue-sources.md) 和 [机器可读入口目录](skills/baoyan-advisor/references/handbooks.json)。当前目录有 35 个入口：23 个入口与主题已核查，3 个目录已核查但正文受限，9 个候选入口。目录只包含链接和简短范围说明，不是手册全文或录取统计样本；引用具体经验时仍需打开原文，涉及当年规则时需核对官方通知。

咨询有两种路径：

1. **直接请求模型 API**：在设置页填写自己的 OpenAI 兼容 API 地址、模型和 Key，再主动发送问题。桌面版由本机应用发送请求；默认不附带个人资料，只有勾选后才附带。此路径只给模型规则摘要和来源链接索引，**不会运行 Codex Skill，也不会自动阅读手册正文**。服务商可能收费，并会收到发送内容。
2. **Codex Skill 交接**：在咨询页生成并检查提问，再复制到能访问本仓库的 Codex 对话。仓库内的 `AGENTS.md` 指引 Codex 读取 Skill，并按问题核查具体来源页面。若对话无法访问本仓库，仅复制文件路径不能加载 Skill。

如需在仓库中保存自己的 Markdown 资料，可复制 [个人资料模板](profile/PROFILE.template.md) 为 `profile/PROFILE.md`。该私人文件已加入 Git 忽略列表，不会由应用自动读取。不要把真实 API Key、个人履历或材料文件放进 Git 仓库。

## 网页预览

若只需查看界面，可用本地静态文件服务器打开 `index.html`。网页预览将清单、咨询资料及 API 配置保存在当前浏览器的 `localStorage`，附件保存在 IndexedDB。网页脚本可以读取浏览器中保存的 API Key；请避免在公共设备长期保存。网页预览不会发送桌面系统提醒。清除浏览器站点数据可能删除这些内容。直接双击 `index.html` 时，本地存储行为可能因浏览器而异。

## 开发与验证

```powershell
node --check app.js
node --check consult.js
node --check files.js
node --check desktop/main.cjs
node tests/storage-smoke.cjs
node tests/consult-smoke.cjs
```

桌面交互测试需要先用**独立的临时用户数据目录**启动 Electron，并开启远程调试端口，然后运行 `node tests/desktop-smoke.cjs <端口>`。该脚本会在目标实例中创建测试项目和提醒，不能连接正式使用的数据目录。

## 文件

- `index.html`、`styles.css`、`app.js`、`consult.js`：可直接编辑的界面与交互。
- `files.js`：桌面文件接口与浏览器预览的文件存储。
- `desktop/`：Electron 窗口、系统通知、本机存储和模型请求。
- `AGENTS.md`、`skills/baoyan-advisor/`：仓库内的保研咨询 Skill 与资料目录。
- `tests/`：桌面交互与本机文件存储的验证脚本。
- `assets/`：图标。

真实招生要求、截止日期和资格条件应以各院校官方通知为准。
