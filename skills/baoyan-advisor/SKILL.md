# 保研咨询

## 入口与资料

- 接受用户直接发来的 Markdown 个人资料和问题。若用户只发问题，先利用已给信息；缺少会改变判断的条件时询问。用户未提供资料时，不假设学校、排名、专业或目标。
- 用户明确要求使用本地资料时，读取仓库根目录的 `profile/PROFILE.md`（如存在）；空白结构见 `profile/PROFILE.template.md`。不要自动创建、提交或展示含个人信息的文件。
- 按问题领域读取 [来源目录](references/feiyue-sources.md)；完整的工作台来源清单位于 [handbooks.json](references/handbooks.json)。选择相关手册的具体文章，并在回答时给出文章链接和阅读日期。来源目录是索引，不是录取数据库，也不表示所有文章已逐篇审阅。

## 查询与判断

1. 先辨认问题类型：国内推免、海外申请，或两者比较。国内推免优先查保研板块；海外飞跃案例只用于对应的海外申请问题或一般方法参考。
2. 需要外部事实时，调用当前环境可用的检索/网页阅读 Agent 或工具，打开相关手册的**具体页面**。若工具不可用，说明未能实时核查，不能把索引页当作文章证据。
3. 涉及当年资格、招生条件、名额、流程和截止时间，继续核对目标院校/学院或主管部门的当年官方通知，写明年份和链接。手册经验不能代替官方规则。
4. 把材料分成官方规定、个人经验、用户提供事实和推测。个案仅说明可能路径，不估算录取概率或推断普遍门槛。不同届别、专业和学校的案例不能直接合并成统计样本。
5. 建议应对应用户条件，列出当前可行动事项、关键待核实条件和核实入口。无法确认的信息明确标为“无确切信息”或“需验证”。

## 工作台入口与 Agent 协作

工作台提供两条不同路径，回答时不要把它们描述成同一项能力：

1. **直连用户配置的模型 API**：工作台把问题、当前 Markdown 资料、规则摘要和 `handbooks.json` 的链接索引发给 OpenAI Chat Completions 兼容接口。这只是在调用模型 API，不会启动 Codex Skill 或 Codex Agent，也不包含手册全文。除非该 API 服务明确提供并实际启用了网页检索工具，否则必须说明未实时读取来源页面。
2. **复制到 Codex 使用本 Skill**：工作台生成包含问题与用户自愿提供资料的 Markdown。用户需把内容复制到能访问本仓库的 Codex 对话中；随后按本 Skill 阅读相关来源索引、调用当前可用的网页检索工具并核查具体页面。脱离本仓库的普通聊天无法仅凭文件路径读取此 Skill。

对多校、多专业或多来源的比较问题，若当前 Codex 环境提供子 Agent，可按院校或申请类型分派独立检索；每个结果必须附具体页面链接、届别和核查范围。主回答者负责交叉核对冲突、剔除无来源结论并综合建议。子 Agent 不可用时，直接检索或说明限制，不要假称已委派。

`handbooks.json` 是链接目录，不是录取统计样本或全文知识库。工作台的项目状态、演示数据不得自动视作用户履历。个人资料只使用用户当前提供的内容；若用户明确要求读取本地资料，再读取 `profile/PROFILE.md`。
